### 1. ollama（ollama/ollama，main，19.3 KB）

「Get up and running with large language models」。随后**不是特性长文，而是
Download**（macOS/Windows/Linux/Docker/Libraries 各一行直达链接）。

| 点位 | 它怎么做 | 值得抄什么 |
|---|---|---|
| 定位句 | 标题下一行、无形容词堆砌，说清「装完能得到什么」 | 一行话=动词+对象，不放「领先的/强大的」 |

| 生态 | Community Integrations 长清单 | 平台型产品用「能被接进什么」证明通用性 |

## 二、共性提炼（五件样本 ≥3 件同现才入列）

1. **一句定位前置**：标题下方一行内说清「它是什么 + 装完能得到什么」，无形容词堆砌。
2. **真实界面图在第一屏**：supabase/n8n/dolphinscheduler 都把 dashboard/工作流截图放在
   定位句与特性列表之间；GIF>截图>文字——动图最贵，截图是底线，纯文字介绍界面=零分。
3. **30 秒 quickstart 是一条可粘贴命令**：n8n `curl | sh`、ollama 下载即装、
   dolphinscheduler Docker 直达；且**命令之后必须有一行「去哪打开」**。
4. **多形态/多意图分流**：体验一条路、生产一条路（dolphinscheduler「想要体验/想上生产」、
   ollama Download×Docker×Libraries、本仓 A/B/C 形态同理）。
5. **徽章栏**：license + 质量证据 + 语言切换（dolphinscheduler 最典型）。
6. **架构一图**：supabase「How it works」SVG；文字细则下沉链接。
7. **特性用短横列不用段落**：dolphinscheduler 8 条、n8n Key Capabilities。
8. **FAQ/疑问预答**：n8n 文末答命名；supabase 答「Translations」；本仓要预答的是
   「一台 8G 机器能不能跑全套」「和阿里云 DataWorks 什么关系」。
9. **README 是门面不是手册**：n8n 全文 4 KB；深度内容一律链出。
10. **诚实边界不藏**：四个样本都以「部署模式/前置条件」写明依赖，不暗示无限免费。
